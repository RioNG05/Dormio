## Key Entity Reference

### BOARDING_HOUSE
- `ownerId` → `User.id` (role=landlord)
- Every BHMS query must filter by `boardingHouseId`
- Scoped via `X-Boarding-House-Id` header + `PropertyOwnershipGuard`

### ROOM
- `status`: `available | deposited | occupied | maintenance`
- `@@unique([boardingHouseId, name])` — reject duplicate room names
- Set `status='occupied'` when contract created (UC-L-04 step 7)
- Set `status='available'` when contract expired/canceled

### CONTRACT
- `source`: `external | platform`
  - `external`: landlord creates directly (UC-L-04), no prior platform deposit
  - `platform`: converted from platform deposit (UC-L-04b)
- `status`: `draft | active | expired | canceled`
- Never hard-delete. Use status transitions.
- `CONTRACT_TENANT`: supports co-tenants. `isPrimary=true` for main tenant.

### DEPOSIT
- `type`: `hold | contract | platform`
  - `hold`: landlord manually holds (UC-L-10), `contractId=NULL`, `postId=NULL`
  - `contract`: external contract deposit (UC-L-04), `contractId=<new>`, `postId=NULL`
  - `platform`: online deposit from BHRP (UC-PU-04), `contractId=NULL`, `postId=<post>`
- `status`: `pending | paid | refunded | forfeited`
- Do NOT create new DEPOSIT when converting platform→contract. UPDATE existing row with `contractId`.
- Auto-refund job: `platform` deposits where `contractId IS NULL` after X days (env var)

### PAYMENT
- `amount` always positive (even refunds)
- `type`: `CHARGE | REFUND`
- Exactly one of FK: `invoiceId`, `depositId`, `postPurchaseId`, `subscriptionId` must be non-null (CHECK constraint)
- `transactionRef`: UNIQUE — use for webhook idempotency
- `originalPaymentId`: self-ref, set on REFUND payments

### INVOICE
- Generated by monthly cron per occupied room
- `INVOICE_DETAIL`: one row for rent (serviceId=NULL), one per active ROOM_SERVICE
- Metered services: `readingValue × unitPrice` from latest confirmed `METER_READING`
- Flat services: fixed price
- `status`: `UNPAID | PAID | OVERDUE`

### METER_READING
- `status`: `pending | confirmed`
- Only `confirmed` readings feed into invoice generation
- Tenant flow: upload image → OCR extracts value → tenant confirms

### POST (BHRP)
- `sourceType`: `free_quota | purchased`
- Quota check before insert: count today's free posts vs plan's `dailyPostQuota`
- If linked to room (`roomId` non-null): validate room ownership
- AI draft (UC-L-12) only prefills form — `POST` not created until landlord explicitly publishes
- `status`: `draft | posted | hidden`

### CONVERSATION / MESSAGE (Chat)
- `user1Id < user2Id` (lexicographic sort) — enforced before upsert
- `@@unique([user1Id, user2Id])`
- Reused for both BHMS (landlord ↔ tenant) and BHRP (poster ↔ platform user)
- Admins cannot be participants

### USER
- `role`: `landlord | tenant | employee | admin`
- `mustChangePassword`: flag for accounts with default password `00000000`
- A person can be both tenant and employee (same USER row). Employee role checked by EMPLOYEE table existence, not USER.role alone.
- Helper: `UserService.findOrCreateByPhone()` — used in UC-L-04 and UC-L-19

### EMPLOYEE / EMPLOYEE_ASSIGNMENT
- `EMPLOYEE_ASSIGNMENT.status`: `active | inactive`
- Setting `inactive` must cascade-cancel future `WORK_SCHEDULE` rows (application-layer, logged to AuditLog)
- Scoped to `boardingHouseId` in assignment

### WORK_SCHEDULE
- Pre-generate concrete rows per recurrence pattern (not computed on-the-fly)
- `recurrencePatternId`: null for ad-hoc, non-null for recurring
- Editing whole pattern: overwrite all future rows including individually-edited ones

### GRIEVANCE
- New table (not in original ERD — must be added)
- `status`: `open | in_review | resolved | rejected`
- Routes to Admin queue on create, notification to tenant on resolution

### MASS_NOTIFICATION_JOB
- New table (not in original ERD — must be added)
- Use BullMQ for fan-out — never loop synchronously in HTTP handler

## Business Rule Quick Reference

| Rule | Implementation |
|---|---|
| Platform deposit → contract | UPDATE existing DEPOSIT.contractId, do NOT insert new DEPOSIT |
| External contract deposit | INSERT DEPOSIT(type=contract, recordedManually=true), NO PAYMENT row |
| Webhook idempotency | UNIQUE on PAYMENT.transactionRef |
| Staff check-in window | [shift.startTime - 10min, shift.startTime] only; 403 outside window |
| Broadcast notifications | NOTIFICATION.receiverId IS NULL = broadcast (not one row per tenant) |
| Posting quota | Check free_quota count today vs plan.dailyPostQuota; then check purchased slots |
| Poster analytics | POST_REACH table tracks view counts |
| Private ID card storage | Serve via short-lived signed URLs only, never public URL |
| UserService.findOrCreateByPhone | Shared helper for UC-L-04 and UC-L-19 |
